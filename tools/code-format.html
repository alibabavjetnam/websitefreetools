Định dạng mã nguồn

Dán mã JavaScript, HTML, CSS hoặc JSON vào, công cụ sẽ căn chỉnh và thụt lề lại cho dễ đọc.

Định dạng và rút gọn mã nguồn

Mã JavaScript, HTML, CSS hay JSON viết liền một dòng hoặc thụt lề lộn xộn rất khó đọc. Công cụ căn chỉnh lại thụt lề, xuống dòng theo chuẩn.

Chọn ngôn ngữ và kiểu thụt lề (2, 4 dấu cách hoặc Tab), rồi định dạng; hoặc nén lại thành một dòng để giảm dung lượng khi đưa lên website.

Mã được xử lý trên trình duyệt, không gửi lên máy chủ. Sao chép hoặc tải kết quả thành file.

Câu hỏi thường gặp

Định dạng có làm thay đổi cách mã chạy không?

Không. Chỉ khoảng trắng và xuống dòng thay đổi.

Nén mã (minify) là gì?

Là bỏ khoảng trắng, xuống dòng để file nhỏ hơn, tải nhanh hơn.

JSON lỗi có định dạng được không?

Không. Hãy tìm vị trí lỗi bằng công cụ Kiểm tra lỗi cú pháp trước.

Có tải kết quả thành file không?

Có, bấm Tải file để lưu mã đã định dạng.

Mã của tôi có bị lưu không?

Không. Mã chỉ được xử lý trên máy bạn.
