Ảnh sang Base64

Nhúng ảnh nhỏ thẳng vào HTML, CSS hoặc mã nguồn mà không cần file riêng.

Khi nào dùng ảnh dạng Base64

Base64 biến ảnh thành một chuỗi chữ có thể dán thẳng vào HTML, CSS hay JSON, không cần file ảnh riêng. Cách này hợp với biểu tượng nhỏ, ảnh trong email hoặc dữ liệu gửi qua API.

Chọn ảnh để nhận chuỗi Base64 hoặc data URI kèm sẵn mã HTML, CSS. Chiều ngược lại, dán chuỗi Base64 để xem lại ảnh và tải về.

Chuỗi Base64 lớn hơn file gốc khoảng một phần ba, nên không nên dùng cho ảnh lớn trên website.

Câu hỏi thường gặp

Data URI là gì?

Là chuỗi bắt đầu bằng data:image/png;base64, dùng trực tiếp trong thuộc tính src của thẻ img hoặc url() trong CSS.

Vì sao chuỗi Base64 dài hơn ảnh gốc?

Base64 viết 3 byte dữ liệu thành 4 ký tự nên dung lượng tăng khoảng 33%.

Có nên dùng Base64 cho mọi ảnh trên web?

Không. Chỉ nên dùng cho ảnh rất nhỏ; ảnh lớn để dạng file sẽ được trình duyệt lưu đệm tốt hơn.

Dán chuỗi Base64 mà không hiện ảnh?

Kiểm tra chuỗi có bị cắt thiếu hoặc lẫn ký tự lạ. Chuỗi có thể có hoặc không có tiền tố data:image.

Ảnh của tôi có bị gửi đi đâu không?

Không. Việc chuyển đổi diễn ra trên máy bạn.
