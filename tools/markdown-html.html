Markdown sang HTML

Soạn Markdown, xem trước ngay và lấy mã HTML; hoặc đổi trang HTML sang Markdown.

Markdown là gì

Markdown là cách viết văn bản có định dạng bằng ký hiệu đơn giản: # cho tiêu đề, **chữ** cho in đậm, - cho danh sách. Nó được dùng ở GitHub, Notion, Reddit, nhiều blog và tài liệu kỹ thuật.

Gõ Markdown bên trái, phần xem trước hiển thị ngay, ô bên dưới là mã HTML để dán vào website hoặc email. Kiểu GitHub hỗ trợ thêm bảng, gạch ngang chữ và xuống dòng tự nhiên.

Tab HTML sang Markdown giúp chuyển nội dung bài viết, trang web cũ sang Markdown để đưa vào hệ thống mới.

Câu hỏi thường gặp

Có hỗ trợ bảng trong Markdown không?

Có. Dùng dấu | để chia cột và dòng |---| dưới tiêu đề, như mẫu có sẵn.

Mã HTML xuất ra có an toàn để dán vào web không?

Phần xem trước được lọc script; mã xuất ra giữ đúng nội dung bạn viết nên hãy kiểm tra nếu nội dung đến từ người khác.

Chuyển HTML sang Markdown có giữ hình ảnh không?

Có. Thẻ <img> được đổi thành cú pháp ![mô tả](đường dẫn).

Có cần mạng để dùng không?

Lần đầu công cụ tải thư viện marked, DOMPurify, Turndown từ CDN; sau đó chạy trên máy bạn.

Markdown có nhiều phiên bản không?

Có: CommonMark, GitHub Flavored Markdown… Công cụ theo chuẩn GitHub phổ biến nhất.
