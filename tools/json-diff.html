So sánh JSON theo cấu trúc

So sánh văn bản thông thường báo khác chỉ vì đổi thứ tự khoá hay khoảng trắng. Công cụ này đọc JSON thành dữ liệu rồi so từng khoá, nên chỉ báo những khác biệt thật về nội dung.

Mỗi khác biệt có đường dẫn dạng $.settings.theme, loại thay đổi (thêm, xoá, đổi giá trị, đổi kiểu) và giá trị ở hai bên, tô màu để dễ nhìn.

Bật Bỏ qua thứ tự phần tử trong mảng khi mảng chỉ là tập hợp (danh sách thẻ, quyền) để không bị báo khác do sắp xếp.

Câu hỏi thường gặp

Thứ tự khoá khác nhau có bị coi là khác không?

Không. Hai đối tượng có cùng khoá và giá trị được coi là giống nhau dù thứ tự khác.

Số 1 và chuỗi 1 có khác không?

Có, được báo là đổi kiểu dữ liệu.

Dùng để làm gì trong thực tế?

So sánh phản hồi API giữa hai phiên bản, file cấu hình giữa môi trường thử và thật, dữ liệu trước và sau khi xử lý.

Có xuất báo cáo được không?

Có. Nút Sao chép báo cáo cho danh sách dạng bảng, dán vào Excel hoặc tin nhắn.

JSON lớn có chạy được không?

JSON vài MB vẫn ổn. Mảng rất dài với tuỳ chọn bỏ qua thứ tự sẽ chậm hơn.
