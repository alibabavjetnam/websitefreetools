Nối và tách file PDF

Gộp nhiều file PDF thành một file duy nhất để nộp hồ sơ, gửi email gọn gàng; hoặc tách lấy những trang cần dùng từ một file dài.

Kéo thả để sắp xếp thứ tự file trước khi gộp. Khi tách, nhập danh sách trang như 1-3, 5 hoặc chia mỗi trang thành một file riêng.

File được xử lý ngay trên trình duyệt nên tài liệu hợp đồng, giấy tờ cá nhân không bị tải lên máy chủ.

Câu hỏi thường gặp

Có giới hạn số file hoặc dung lượng không?

Không có giới hạn cố định; file rất lớn tuỳ thuộc bộ nhớ máy bạn.

Gộp PDF có làm giảm chất lượng không?

Không. Các trang được chép nguyên vẹn sang file mới.

File PDF có mật khẩu gộp được không?

Không. Hãy mở khoá file trước bằng phần mềm có mật khẩu.

Muốn xoay hoặc đánh số trang thì sao?

Dùng công cụ Xoay, đánh số, xoá trang PDF.

Tài liệu có bị gửi lên mạng không?

Không. Mọi xử lý diễn ra trên máy bạn.
