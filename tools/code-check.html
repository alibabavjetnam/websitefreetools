Kiểm tra lỗi cú pháp

Dán mã vào để tìm lỗi cú pháp và cấu trúc. Công cụ chỉ ra vị trí dòng, cột của từng lỗi.

Tìm lỗi cú pháp trong mã

Một dấu ngoặc thiếu hay dấu phẩy thừa có thể làm cả trang web hoặc file cấu hình hỏng. Công cụ phân tích cú pháp JavaScript, HTML, CSS, JSON và chỉ ra dòng, cột có lỗi.

Dán mã, chọn ngôn ngữ và bấm kiểm tra. Mỗi lỗi có mô tả ngắn và vị trí để bạn sửa nhanh.

Công cụ kiểm tra cú pháp, không chạy mã nên không phát hiện được lỗi logic.
