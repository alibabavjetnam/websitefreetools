Chuyển đổi YAML, JSON, TOML

Đổi file cấu hình qua lại giữa YAML, JSON và TOML, báo lỗi cú pháp kèm vị trí.

Ba định dạng cấu hình phổ biến

JSON chặt chẽ, dùng nhiều trong API. YAML dễ đọc nhờ thụt lề, phổ biến ở Docker Compose, Kubernetes, GitHub Actions. TOML rõ ràng theo bảng, dùng cho Cargo (Rust), pyproject (Python), Hugo.

Chọn định dạng nguồn và đích, kết quả cập nhật khi bạn gõ. Nút Đổi chiều đưa kết quả lên làm dữ liệu nhập để chuyển ngược.

TOML không có giá trị null và cần gốc là một bảng, nên các trường null bị bỏ khi chuyển sang TOML. Chú thích trong YAML/TOML không được giữ lại.

Câu hỏi thường gặp

YAML báo lỗi thụt lề là sao?

YAML dùng dấu cách để biểu diễn cấp; không được dùng Tab và các mục cùng cấp phải thẳng hàng.

Chuyển YAML sang JSON có mất dữ liệu không?

Không mất dữ liệu, chỉ mất chú thích và neo (&, *) được bung ra thành giá trị cụ thể.

Vì sao yes/no trong YAML thành true/false?

Thư viện dùng chuẩn YAML 1.2 nên yes/no giữ là chuỗi; chỉ true/false mới là kiểu đúng/sai.

Có cần mạng để chạy không?

Lần đầu công cụ tải thư viện js-yaml và smol-toml từ CDN, sau đó mọi xử lý diễn ra trên máy bạn.

Ngày giờ trong TOML được giữ không?

Ngày giờ TOML được đổi thành chuỗi ISO khi sang JSON/YAML.
