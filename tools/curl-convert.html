Chuyển lệnh cURL sang mã

Dán lệnh cURL (ví dụ Copy as cURL trong trình duyệt) để có ngay mã gọi API tương ứng.

Cách chuyển cURL sang mã nguồn

cURL là lệnh gửi yêu cầu HTTP phổ biến trong tài liệu API. Công cụ đọc phương thức, địa chỉ, tiêu đề (-H), dữ liệu gửi (-d, --json), biểu mẫu (-F) và tài khoản (-u) rồi viết lại bằng ngôn ngữ bạn chọn.

Dữ liệu JSON được nhận ra và viết thành đối tượng gọn gàng (JSON.stringify, json= trong Python). Tài khoản -u được đổi thành tiêu đề Authorization Basic.

Mẹo: mở công cụ phát triển (F12) → Network, bấm chuột phải một yêu cầu → Copy → Copy as cURL (bash) rồi dán vào đây để tái tạo đúng yêu cầu đó.

Câu hỏi thường gặp

Có hỗ trợ lệnh cURL nhiều dòng với dấu \ không?

Có. Dấu \ ở cuối dòng được nối lại tự động.

Copy as cURL trên Windows (cmd) dùng được không?

Nên chọn bản bash. Bản cmd dùng ký tự ^ để thoát nên có thể đọc sai.

Token trong lệnh có bị gửi đi đâu không?

Không. Việc chuyển đổi chạy trên trình duyệt. Dù vậy, đừng chia sẻ mã có token thật.

Gọi API bằng fetch từ trình duyệt bị lỗi CORS?

Đó là giới hạn của máy chủ API, không phải lỗi mã. Hãy gọi từ máy chủ (Node.js) hoặc bật CORS phía API.

Tuỳ chọn nào bị bỏ qua?

Các tuỳ chọn hiển thị và mạng như -o, -w, --max-time, -x không có tác dụng trong mã nên được bỏ qua.
