Tạo file .gitignore

Chọn ngôn ngữ, framework, hệ điều hành và trình soạn thảo để ghép file .gitignore cho dự án.

File .gitignore để làm gì

File .gitignore liệt kê những file, thư mục Git không theo dõi: thư viện tải về (node_modules), file build, file cấu hình chứa mật khẩu (.env), file rác của hệ điều hành và trình soạn thảo.

Chọn các mục phù hợp với dự án, công cụ ghép thành một file có tiêu đề từng phần. Bạn có thể thêm dòng riêng ở ô cuối.

Tải file về và đặt ở thư mục gốc dự án với đúng tên .gitignore (có dấu chấm ở đầu, không có đuôi).

Câu hỏi thường gặp

Thêm vào .gitignore rồi mà file vẫn bị theo dõi?

File đã được commit trước đó vẫn bị theo dõi. Chạy git rm --cached tên-file rồi commit lại.

Có nên đưa file .env vào Git không?

Không. Đưa vào .gitignore và tạo file .env.example không chứa giá trị thật để người khác biết cần những biến nào.

Dấu ! trong .gitignore nghĩa là gì?

Là ngoại lệ: không bỏ qua file khớp mẫu đó, dù dòng trước đã bỏ qua cả thư mục.

Windows không cho đặt tên .gitignore?

Lưu file với tên .gitignore. (có dấu chấm ở cuối) hoặc tạo bằng VS Code, Windows sẽ tự bỏ dấu chấm cuối.

Mẫu có lấy từ GitHub không?

Mẫu do WFTools tự soạn gọn, theo các quy ước phổ biến của từng công nghệ.
