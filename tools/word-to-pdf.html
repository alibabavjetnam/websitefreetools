Word sang PDF

Chọn file .docx, xem trước nội dung rồi tải về PDF. File không rời khỏi máy bạn.

Chuyển Word sang PDF

Chuyển file Word .docx sang PDF để gửi đi mà không lo lệch phông, lệch bố cục trên máy người nhận.

Tải file PDF tạo PDF ngay với mỗi trang là ảnh chất lượng cao. In / Lưu PDF dùng hộp thoại in của trình duyệt để có chữ sắc nét, chọn được.

File được đọc ngay trên máy bạn, không tải lên máy chủ, tối đa 50 MB.

Câu hỏi thường gặp

Có hỗ trợ file .doc cũ không?

Chưa. Mở bằng Word và lưu lại dạng .docx.

Cách nào cho chữ sắc nét?

Dùng In / Lưu PDF và chọn máy in Lưu thành PDF.

Bố cục có giống Word không?

Gần giống với văn bản thông thường; bố cục phức tạp có thể khác chút.

Giới hạn file bao nhiêu?

50 MB.

File có bị tải lên không?

Không, xử lý trên máy bạn.
