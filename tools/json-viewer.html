Xem JSON dạng cây, JSONPath

Mở JSON dạng cây dễ đọc, bấm để lấy đường dẫn và lọc dữ liệu bằng JSONPath.

Cách đọc và truy vấn JSON

Dán JSON vào ô bên trái, cây bên phải hiện từng đối tượng, mảng kèm số phần tử. Bấm vào mũi tên để mở hoặc thu gọn, bấm vào một dòng để lấy đường dẫn JSONPath của nó.

JSONPath giống địa chỉ của dữ liệu: $ là gốc, .ten là trường, [0] là phần tử đầu, [*] là mọi phần tử, .. là tìm ở mọi độ sâu, [?(@.gia<35)] là lọc theo điều kiện.

Nút Làm đẹp căn lề JSON, nút Sắp xếp khoá A-Z giúp so sánh hai JSON dễ hơn.

Câu hỏi thường gặp

JSONPath có giống XPath không?

Ý tưởng giống: viết đường dẫn để chọn dữ liệu. JSONPath dành cho JSON, XPath dành cho XML.

Công cụ hỗ trợ những biểu thức lọc nào?

So sánh ==, !=, >, <, >=, <= với số hoặc chuỗi, và kiểm tra trường có tồn tại [?(@.ten)].

JSON báo lỗi ở đâu?

Thông báo lỗi kèm vị trí ký tự sai; lỗi hay gặp là dấu phẩy thừa ở cuối hoặc dùng nháy đơn thay nháy kép.

Dữ liệu có bị gửi đi không?

Không. JSON được xử lý hoàn toàn trên trình duyệt.

Mở được file JSON rất lớn không?

Vài MB vẫn ổn; file hàng chục MB có thể làm cây hiển thị chậm.
