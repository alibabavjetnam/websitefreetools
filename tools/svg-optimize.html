Tối ưu và nén SVG

Làm gọn file SVG từ phần mềm thiết kế, giảm dung lượng mà hình hiển thị vẫn như cũ.

Vì sao file SVG cần tối ưu

File SVG xuất từ Inkscape, Illustrator, Figma thường chứa nhiều dữ liệu riêng của phần mềm, chú thích, số thập phân dài. Bỏ đi có thể giảm 30 đến 70% dung lượng.

Công cụ làm tròn toạ độ theo số chữ số thập phân bạn chọn (2 là đủ cho biểu tượng), rút gọn đường path, bỏ nhóm rỗng và khoảng trắng thừa.

So sánh hình trước và sau ngay bên dưới. Nếu thấy hình bị lệch, tăng số chữ số thập phân lên 3.

Câu hỏi thường gặp

Tối ưu có làm mờ hình không?

Không. SVG là hình vector; làm tròn hợp lý không thấy khác bằng mắt.

Bỏ width/height để làm gì?

Hình sẽ co giãn theo khung chứa trên web, chỉ giữ viewBox để đúng tỉ lệ.

Data URI dùng ở đâu?

Dán thẳng vào CSS background-image hoặc thẻ <img src> mà không cần file riêng.

Có hỗ trợ SVG có ảnh nhúng không?

Có, ảnh nhúng được giữ nguyên; muốn nhẹ hơn hãy nén ảnh đó riêng.

Công cụ có dùng SVGO không?

Không. WFTools tự viết bộ tối ưu nhẹ chạy trên trình duyệt.
