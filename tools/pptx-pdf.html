PowerPoint ↔ PDF

Đổi bài trình chiếu sang PDF để gửi, in ấn, hoặc biến file PDF thành PowerPoint để trình chiếu. Không tải file lên máy chủ.

Chuyển đổi PowerPoint và PDF

Chuyển bài trình chiếu .pptx sang PDF để gửi, in hoặc trình chiếu trên máy không có PowerPoint; hoặc biến file PDF thành bài PowerPoint với mỗi trang là một slide.

Chọn file, công cụ đọc nội dung và tạo file mới ngay trên trình duyệt, không cần cài Office.

Khi chuyển PDF sang PowerPoint, mỗi trang thành một ảnh trên slide nên giữ đúng hình thức nhưng chữ không sửa trực tiếp được.

Câu hỏi thường gặp

Chuyển PPTX sang PDF có giữ phông chữ không?

Phông có sẵn trên máy sẽ hiển thị đúng; phông đặc biệt không có có thể được thay bằng phông gần giống.

Hiệu ứng chuyển slide có giữ lại không?

Không. PDF là tài liệu tĩnh nên hiệu ứng và chuyển cảnh bị bỏ.

PDF sang PowerPoint có sửa chữ được không?

Mỗi trang được đặt thành ảnh nên chữ không sửa trực tiếp; bạn có thể thêm hộp chữ mới lên trên.

Có hỗ trợ file .ppt cũ không?

Công cụ hỗ trợ .pptx. File .ppt cũ hãy lưu lại thành .pptx trước.

File có bị tải lên máy chủ không?

Không. Chuyển đổi diễn ra trên trình duyệt.
